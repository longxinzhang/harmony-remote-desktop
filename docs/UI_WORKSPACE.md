# 桌面工作区与开发测试入口

界面自 0.5.0-rc.2 起按远程桌面工具的常见结构整理：侧边导航、连接信息卡片、会话操作区和独立的开发测试页。0.6.0-rc.1 在此结构中加入配对、恢复、声音和启动设置。沿用 Harmony Remote 名称与现有原生实现；没有引入 RustDesk 代码或服务，也没有增加互联网中继、设备发现、绕过本机授权的无人值守访问或文件传输。

## 页面分工

| 页面 | Mac 控制端 | 鸿蒙受控端 |
| --- | --- | --- |
| 远程桌面 | 地址/PIN、记住设备与已配对设备；远端画面、控制、剪贴板、静音、网络状态及断开/取消重连 | 本机连接信息、服务与手动共享、重连状态、键鼠权限、控制与剪贴板同步 |
| 设置 | 键盘与剪贴板、自动重连、移除配对、静音、登录 Mac 后启动及实际系统状态 | 会话模式、30/60 FPS、共享系统声音、允许新增/撤销可信设备、自启动状态查询、应用启动后监听、本机地址与输入撤销 |
| 开发测试 | 连接、接收/解码/显示、网络 RTT/抖动/速率、声音及输入/剪贴板状态、导出与本地回放说明 | 原有录屏/编码/延迟输入探针，以及配对、重连、音频状态与诊断保存 |

主流程提供易读的操作状态。底层返回码、帧数、格式分类和原始诊断保留在开发测试页；遇到失败时可从日常操作页面进入查看详情。纯文字剪贴板仍遵守现有协议，文件、图片及保留排版的复制粘贴不在当前范围内。

“10 分钟调试”和“永久上线”仍是鸿蒙端明确选择并保存的两种会话模式。打开开发测试页本身不会修改模式，也不会启动录屏、编码或输入测试。永久上线表示共享没有自动结束时限；应用启动后监听默认为关闭，用户可单独选择。开始共享仍需本机系统授权。30/60 FPS 和系统声音选项仅可在停止当前共享后调整，于下一次共享生效。

Mac 登录启动与鸿蒙的系统自启动状态分别显示。鸿蒙 API 26 普通应用只有查询接口，不能把「打开应用后自动开启服务」显示成系统开机自启已开启。配对也不自动开启录屏、键鼠或剪贴板权限；首次 PIN 配对依赖可信局域网，当前传输未加密。

## 导航与会话生命周期

Mac 的三个页面共享同一个 `ViewerModel`。切页不重新连接、不重置剪贴板方向，也不销毁当前视频视图；只有一个 `VideoSurface` 消费显示帧。离开远程桌面页会先释放键鼠焦点和按键，并取消待执行的受保护粘贴。隐藏的视频视图停止安排显示，最多保留一个最新的待显示帧；连接与解码继续，返回时恢复显示，重新点击画面才取得输入焦点。页面切换不是暂停远端共享。

鸿蒙页面保留在同一个 `Index` 组件内，避免触发离开组件时的服务清理。切页不关闭服务或共享。离开开发测试页会取消尚未执行的延迟输入动作，并停止该页的动态测试图案；图案只在开发页且相关编码运行时更新。本机录屏或编码测试运行时，先在开发测试中停止或等待测试结束，才可开启局域网服务；服务运行时本机测试停用。真正关闭应用仍释放输入并结束服务与共享。

空闲界面检查无需启动服务或共享：

1. 分别打开三个页面并返回，确认导航、表单、滚动和主要按钮可见，不出现原始 JSON 或开发计数挤占首页的情况。
2. 切页前后对比设备地址、配对码输入、会话模式和剪贴板方向，确认没有被导航自动改写。检查开发页没有自动触发测试或授权弹窗。
3. 输入不完整的连接信息时，应提示修正，仍保持未连接；断开、远端复制和控制按钮按当前能力禁用。
4. 以最小窗口尺寸检查排版，并使用可访问性树确认隐藏页面的表单和视频区不能获得操作焦点。

下一次经过用户授权的实际会话需补测：

1. 共享中在两端切换页面，确认服务未中断；Mac 返回画面后显示恢复。
2. Mac 远程拖动或按住修饰键时离开远程桌面页，确认远端立即释放；待确认的剪贴板粘贴不能在其它页面执行。
3. 鸿蒙开发页安排延迟输入后切页，确认倒计时取消；普通模式与永久共享不因开发页导航发生切换。
4. 在系统授权弹窗、拒绝授权、断开与重新连接后确认状态和操作入口一致；对备忘录新复制文字、立即粘贴及实际 CPU/内存占用继续按原验收矩阵记录。

上述列表是验证计划，不表示所有场景已执行。旧版构建、空闲界面检查和安装结果保持独立归档；新增版本的界面、实时输入、剪贴板和共享结果需使用配套构建并记录新的实机证据。
