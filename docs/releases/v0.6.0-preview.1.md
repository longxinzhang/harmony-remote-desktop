# Harmony Remote 0.6.0 Preview 1

通过任意设备远程控制你的鸿蒙电脑。**Designed by DDG**

这是首个带公开下载附件的开发预览版。当前支持 **Apple Silicon Mac（macOS 14+）控制同一可信局域网中的 HarmonyOS PC（API 26 / arm64）**。“任意设备”是产品愿景，其他控制端尚未提供。

产品版本为 **0.6.0**，Mac build **9**，Harmony Host build **1000013**。本次发布整理现有主线的安装包和文档，不新增远控功能。它不是稳定版，也不代表所有计划功能均已完成真机验收。

| 附件 | 用途与安装条件 |

## 这版可以体验什么

- 鸿蒙桌面采集、H.264 硬件编码与 Mac 硬件解码。
- 远程键鼠、右键、快捷键映射、窗口拖动与文字拖选。
- 关闭 / 单向 / 双向纯文字剪贴板，以及独立的授权开关。
- 远程桌面、设置、开发测试分开的产品界面。
- 网络 RTT、接收帧率、视频码率及采集、解码、显示诊断。
- 自研 **HRD 应用层协议**；底层采用 TCP/IP、H.264、PCM 和系统框架。

已实现持久配对、断线恢复、30 / 60 FPS 选择、系统声音与启动选项，但这些功能的完整真机矩阵仍需补测，不能按稳定版承诺。

## 鸿蒙端授权，一眼看懂

| 授权或开关 | 为什么需要 | 不允许的影响 |
| --- | --- | --- |
| 网络权限 `INTERNET` | 与局域网中的 Mac 建立连接 | 无法远程连接；权限名不表示必须联网到云端 |
| 系统屏幕共享确认 | 允许发送你选择共享的桌面画面 | Mac 无法看到桌面 |
| 系统键鼠授权 + 应用“允许远程控制” | 允许 Mac 操作这台鸿蒙电脑 | 仍可观看已共享的画面，不能远程点击或输入 |
| 剪贴板读取 `READ_PASTEBOARD` | 获取鸿蒙端新复制的纯文字，同步到 Mac | 鸿蒙 → Mac 不可用；它还要求安装签名包含对应 ACL |
| 系统声音开关 | 将鸿蒙正在播放的声音传到 Mac | 无声音；默认关闭，不采集麦克风 |

还需要在 Mac 启用控制或选择剪贴板方向，才能使用对应功能。权限弹窗未再次出现时，应以页面授权状态和实际效果判断；已授权状态可能被系统记住。停止共享、关闭控制、关闭剪贴板同步各有独立入口，详见安装文档。

## 当前问题和验证边界

1. **仅用于可信局域网，传输尚未加密。** 配对身份签名不等于画面、键鼠、剪贴板与声音已加密；不应把监听端口暴露到公网。
2. **密码场景仍可能遮挡受保护窗口。** 当前 AionUI 网页复测为网页窗口黑、窗口外桌面正常，离开密码框后恢复；还不能保证只遮住密码区域，应用登录窗与系统认证框未全部验收。
3. **剪贴板仅支持纯文字。** 备忘录等应用曾出现远程复制后保留旧内容的问题，已有修复但完整兼容性回归仍在进行；遇到异常先关闭同步。文件、图片、富文本及跨设备文件拖放尚不支持。
4. **系统声音、60 FPS、真实断网/重启后的配对恢复、登录启动仍待完整真机验收。** 60 FPS 是目标值，不是恒定输出承诺。鸿蒙“打开应用后启动服务”不是系统开机自启，也不会自动取得共享权限。
5. **长时间使用仍是预览验证范围。** 已有限制缓存和待处理任务的释放机制、长连接使用记录及短时内存采样；累计十几万解码帧不等于缓存十几万图片，但尚未完成 8～24 小时稳定性验收。
6. **安装兼容性有限。** Mac ZIP 未公证，未在其他人的干净 Mac 上验收；鸿蒙下载包尚未签名，不能直接安装，也没有宣称完成其他设备安装验证。
